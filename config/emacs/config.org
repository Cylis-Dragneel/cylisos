* Modules
This file serves as the entry point for the modular configuration.
Each module is an org file in the =modules/= directory, loaded via org-babel.
#+begin_src emacs-lisp
(let ((module-dir (expand-file-name "modules" user-emacs-directory)))
  (mapc (lambda (f)
          (org-babel-load-file (expand-file-name f module-dir)))
        (directory-files module-dir nil "^[0-9]+.*\\.org$")))
#+end_src
